how to play

  • register now, then open challenges at 14:30.
  • every challenge hides a flag. paste it in to score, e.g. KCLCTF{s33_y0u_th3r3}. each description says its format.
  • start with anything tagged browser-only. stuck? every challenge has a free hint.
  • top score at 15:30 wins an amazon gift card.

tools that run in your browser

  • cyberchef: decode anything (base64, hex, rot13...)
  • hexed.it: look inside and edit any file
  • aperi'solve: hidden data in images
  • your browser's dev tools (f12): page source, network requests, javascript

rules

  • play solo. don't attack the scoreboard or other players, only the challenges.
  • don't share flags. ask us for help instead, that's what we're here for.
